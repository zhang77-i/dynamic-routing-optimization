# ALNS Heuristic Module

## Purpose

Adaptive Large Neighborhood Search for dynamic vehicle routing.

## Workflow

1. Generate initial solution
2. Destroy part of routes
3. Repair routes with insertion operators
4. Evaluate objective
5. Accept improved solution

## Operators

- Random removal
- Worst removal
- Greedy insertion
- Regret insertion

The module focuses on explainable optimization decisions for logistics scenarios.
